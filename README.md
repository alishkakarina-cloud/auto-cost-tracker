# Auto Cost Tracker

Личный калькулятор полной себестоимости автомобиля при завозе (например, из ОАЭ в Кыргызстан). Считает итог одновременно в трёх валютах: AED, USD, KGS.

## Возможности

- Поля: цена авто, логистика/доставка, растаможка/пошлины, прочие расходы (агент, страховка, подготовка) — для каждого поля можно выбрать валюту, в которой оно оплачено (AED / USD / KGS).
- Курс AED→USD — фиксированный (3.6725), можно менять вручную.
- Курс USD→KGS — вводится вручную или обновляется одной кнопкой через бесплатный публичный API [open.er-api.com](https://www.exchangerate-api.com/docs/free) (без ключей и регистрации).
- Итоговая себестоимость показывается сразу в трёх валютах.
- История расчётов сохраняется в браузере (localStorage) — без базы данных и без входа в аккаунт. История видна только на устройстве, где считали.

## Стек

Обычный статический сайт: HTML + CSS + JS, без сборки и фреймворков — самый быстрый вариант для личного инструмента и мгновенного деплоя на Vercel.

## Локальный запуск

Просто открыть `index.html` в браузере, либо поднять любой статический сервер:

```bash
npx serve .
```

## Деплой

Проект — статические файлы, поэтому Vercel деплоит его без какой-либо сборки (Framework Preset: Other).
