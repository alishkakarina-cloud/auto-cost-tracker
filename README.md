# Auto Cost Tracker

Личный трекер бизнеса по завозу авто (например, из ОАЭ в Кыргызстан): калькулятор полной себестоимости в трёх валютах (AED / USD / KGS) плюс учёт авто, сделок, клиентов, поставщиков, расходов, аналитики и задач.

Сайт закрыт общим паролем — вход один на всё приложение, без регистрации пользователей.

## Разделы

- **Главная** — KPI (капитал, авто в работе, потенциальная прибыль, сделок за месяц), быстрый переход в калькулятор, последние расчёты, график прибыли.
- **Калькулятор** — цена авто, логистика/доставка, растаможка/пошлины, прочие расходы (агент, страховка, подготовка); для каждого поля свой выбор валюты. Итог сразу в AED / USD / KGS. Расчёт можно сохранить как авто «в работе».
- **Мои авто** — список авто со статусом «в работе» / «продано».
- **Сделки** — продажи с привязкой к авто и клиенту, прибыль считается автоматически.
- **Клиенты**, **Дубай** (поставщики) — простые справочники.
- **Расходы** — общие расходы бизнеса (не привязанные к конкретному авто).
- **Аналитика** — прибыль по месяцам, топ клиентов, общие показатели.
- **Задачи** — чек-лист.
- **Курсы** — курс AED→USD (фиксированный, редактируется вручную) и USD→KGS (вручную или кнопкой через бесплатный публичный API [open.er-api.com](https://www.exchangerate-api.com/docs/free), без ключей и регистрации).

## Хранение данных

Все данные (кроме сессии входа) хранятся в общем JSON-документе в [Vercel Blob](https://vercel.com/docs/vercel-blob) — родном хранилище Vercel, без сторонних платных интеграций. Данные одни для всех устройств, где введён пароль.

## Стек

Next.js (Pages Router) + серверные API-роуты, без базы данных и ORM — вся структура состояния хранится одним JSON-документом. Простая аутентификация: пароль из переменной окружения `APP_PASSWORD`, подписанная cookie-сессия на `SESSION_SECRET`.

## Переменные окружения

- `APP_PASSWORD` — пароль для входа в приложение.
- `SESSION_SECRET` — секрет для подписи cookie сессии.
- `BLOB_READ_WRITE_TOKEN` — токен хранилища Vercel Blob (создаётся автоматически при подключении Blob-стора к проекту).

## Локальный запуск

```bash
npm install
npm run dev
```

Создайте `.env.local` с переменными выше (значения — в настройках проекта на Vercel).

## Деплой

Проект подключён к GitHub-репозиторию — Vercel собирает и деплоит автоматически при пуше в `main`.
